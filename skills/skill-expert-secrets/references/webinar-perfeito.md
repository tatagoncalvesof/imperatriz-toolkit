## Segredo #11: A Pilha (Stack Slide)

O Stack Slide e a ferramenta de vendas mais poderosa do webinar. Cada item e revelado UM POR UM, acumulando valor visual.

### Estrutura do Stack Slide

```
┌──────────────────────────────────────────┐
│  O QUE VOCE VAI RECEBER:                 │
│                                          │
│  ✓ [Produto Principal]                   │
│    Masterclass completa ........ R$ X.XXX│
│                                          │
│  ✓ [Ferramenta 1]                        │
│    Templates prontos ........... R$ X.XXX│
│                                          │
│  ✓ [Ferramenta 2]                        │
│    Planilhas automatizadas ..... R$ X.XXX│
│                                          │
│  ✓ [Bonus 1]                             │
│    Comunidade exclusiva ........ R$ X.XXX│
│                                          │
│  ✓ [Bonus 2]                             │
│    Mentoria em grupo ........... R$ X.XXX│
│                                          │
│  ✓ [Bonus 3]                             │
│    Acesso vitalicio ............ R$ X.XXX│
│                                          │
│  ──────────────────────────────────────  │
│  VALOR TOTAL:                  R$ XX.XXX │
│                                          │
│  ★ INVESTIMENTO HOJE:         R$ X.XXX ★ │
│                                          │
└──────────────────────────────────────────┘
```

### Regras do Stack

1. **Revelar um item por vez:** Cada item aparece sozinho, voce fala sobre ele, e so depois revela o proximo
2. **Valor-ancora individual:** Cada item tem seu preco "se fosse vendido separado"
3. **Acumular visualmente:** O slide vai crescendo — no final, o prospecto ve o valor total enorme
4. **Desconto de 90%:** O preco real deve ser ~10% do valor-ancora total
5. **Nao detalhar modulos:** NAO explique semana por semana. De uma visao geral rapida (30 segundos)
6. **Cada bonus mata uma objecao:** Templates → "nao sei fazer", Comunidade → "vou me sentir sozinho", Mentoria → "preciso de ajuda"

### Como Apresentar o Stack

```
"O que voce vai receber:

Primeiro, voce recebe [Produto Principal] — isso sozinho vale R$X.XXX
porque [beneficio principal].

Alem disso, voce tambem recebe [Ferramenta 1] — eu vendo isso
separadamente por R$X.XXX. Isso vai [beneficio da ferramenta].

E nao para por ai. Voce tambem leva [Bonus 1] — R$X.XXX de valor
porque [beneficio do bonus].

[Continua empilhando...]

Se voce somasse tudo, o valor total seria R$XX.XXX.
Mas voce NAO vai pagar R$XX.XXX.
Voce nao vai pagar nem metade disso.

Seu investimento hoje e apenas R$X.XXX."
```

### PARTE 3: OS 3 SEGREDOS (45-60 minutos) — Segredos #14

Para CADA segredo (repita 3x):

**Estrutura de cada Segredo:**

```
1. DECLARACAO DA FALSA CRENCA
   "A maioria das pessoas acredita que [falsa crenca]..."

2. HISTORIA DA PONTE DA EPIFANIA
   Conte uma historia que quebra essa crenca
   (Use o roteiro de 8 passos)

3. NOVA CRENCA
   "A verdade e que [nova crenca]..."

4. CASO DE ESTUDO (opcional)
   Historia de aluno/cliente que prova a nova crenca

5. TRIAL CLOSE
   "Faz sentido pra voce?" / "Voce consegue ver como isso funciona?"
```

**Segredo #1 → Quebra crenca sobre o VEICULO**
"Sera que funciona?" → Historia provando que SIM

**Segredo #2 → Quebra crenca INTERNA**
"Sera que EU consigo?" → Historia provando que QUALQUER UM consegue

**Segredo #3 → Quebra crenca EXTERNA**
"Mas eu nao tenho tempo/dinheiro/equipe" → Historia provando que nao precisa

## Segredo #16: Encerramentos de Teste (Trial Closes)

Trial Closes sao micro-fechamentos inseridos AO LONGO de TODA a apresentacao — nao so no final.

### O que sao Trial Closes

Perguntas simples que fazem o publico dizer "sim" mentalmente, construindo concordancia progressiva.

### Impacto Comprovado
Russell testou: adicionar trial closes a um webinar automatizado fez o valor por inscrito saltar de **$9.45 para $16.50** — so com os trial closes.

### 12 Trial Closes para Usar

Inserir ao longo da apresentacao, especialmente apos cada ponto importante:

```
1.  "Faz sentido pra voce?"
2.  "Voce consegue ver como isso funciona?"
3.  "Voce esta comecando a perceber o poder disso?"
4.  "Imagina se voce tivesse isso no seu negocio?"
5.  "Legal, ne?"
6.  "Voce ve como isso e diferente do que voce ja tentou?"
7.  "Se eu te mostrasse como fazer isso, voce estaria interessado?"
8.  "Isso faz sentido ate aqui?"
9.  "Voce consegue imaginar o impacto disso na sua vida?"
10. "Ja esta vendo as possibilidades?"
11. "Se isso funcionasse pra voce, quanto valeria?"
12. "Voce esta pronto para [resultado desejado]?"
```

### Onde inserir Trial Closes

- Apos cada ponto importante
- Apos cada historia de sucesso
- Antes de passar para o proximo segredo
- Durante a revelacao de cada item do stack
- Antes de revelar o preco
- Depois de cada fechamento

### Regra: minimo 15-20 trial closes por webinar
