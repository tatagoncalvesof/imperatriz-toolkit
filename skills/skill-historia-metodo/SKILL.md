# Criador de Historia de Metodo & Especialista

Transformar blueprints tecnicos e informacoes sobre metodos em narrativas de autoridade que estabelecem o especialista como referencia no nicho.

## Workflow

### Passo 0: Receber o Blueprint

Antes de qualquer coisa, solicitar o blueprint/documento tecnico do metodo. Aceitar:
- Documento PDF/DOCX/TXT com a estrutura do metodo
- Descricao verbal detalhada do metodo
- Framework/modelo visual descrito em texto
- Estrategia comercial documentada

Analisar o blueprint para extrair:
- Estrutura e pilares do metodo
- Diferenciais unicos da abordagem
- Elementos tecnicos que trazem credibilidade
- Linguagem e terminologia propria

### Passo 1: Definir Tom e Formato

Perguntar qual tom melhor representa a marca:

| Tom | Ideal para | Caracteristicas |
|-----|-----------|-----------------|
| Profissional & Tecnico | B2B, SaaS, corporativo | Dados, frameworks, ROI |
| Acessivel & Educativo | Cursos, consultoria, mentoria | Didatico, passo-a-passo, exemplos |
| Inspirador & Visionario | Startups, inovacao, disruptivo | Futuro, transformacao, missao |
| Descontraido & Proximo | B2C, lifestyle, creators | Informal, pessoal, autenticidade |

Perguntar formato de saida desejado:
- Historia completa (documento longo)
- Copy para vendas (landing page, emails)
- Roteiro para video/apresentacao
- Carrossel para Instagram
- Pitch para investidores/parceiros
- Todos os formatos

### Passo 2: Extrair Narrativa do Blueprint

Analisar o blueprint e preencher a Matriz de Autoridade:

```
MATRIZ DE AUTORIDADE
1. PROBLEMA CENTRAL — Que dor o metodo resolve?
2. INSIGHT UNICO — O que o especialista percebeu que outros nao veem?
3. PILARES DO METODO — Quais sao os componentes estruturais?
4. MECANISMO UNICO — Como funciona de forma diferente?
5. PROVA DE CONCEITO — Que resultados ja existem?
6. EVOLUCAO — Como o metodo amadureceu?
7. VISAO DE FUTURO — Para onde o metodo esta indo?
```

### Passo 3: Perguntas Estrategicas

Fazer as 7 perguntas fundamentais baseadas na analise do blueprint. Ver [references/perguntas-estrategicas.md](references/perguntas-estrategicas.md) para templates completos.

Oferecer 3 opcoes de processo:
- **Opcao A (Rapida):** Analisar blueprint e gerar narrativa com perguntas minimas
- **Opcao B (Dirigida):** Perguntas estrategicas uma por uma (mais profundo)
- **Opcao C (Guiada):** Contar a historia identificada e pedir complementos

### Passo 4: Construir a Narrativa

Usar a estrutura de 6 blocos da Narrativa de Autoridade. Ver [references/estrutura-narrativa.md](references/estrutura-narrativa.md) para frameworks completos.

**Estrutura obrigatoria:**
1. Origem do Especialista (jornada pessoal)
2. O Insight Unico (momento de revelacao)
3. Desenvolvimento do Metodo (como foi construido)
4. Validacao e Resultados (provas sociais)
5. Visao de Especialista (futuro do nicho)
6. Chamada de Autoridade (por que seguir voce)

### Passo 5: Adaptar por Formato

Adaptar a narrativa para os formatos solicitados. Ver [references/formatos-saida.md](references/formatos-saida.md) para templates de cada formato.

## Principios de Escrita

1. **Veracidade primeiro** — Nunca inventar fatos, apenas estruturar os reais
2. **Especificidade gera credibilidade** — Numeros, datas, nomes > generalidades
3. **Vulnerabilidade controlada** — Mostrar desafios reais (nao fraquezas)
4. **Tecnico como prova** — Elementos do blueprint demonstram profundidade
5. **Transformacao > informacao** — Focar no impacto, nao na teoria
6. **Uma historia por vez** — Nao misturar multiplas narrativas

## Gatilhos Psicologicos na Narrativa

Incorporar naturalmente (sem forcar):
- **Autoridade:** Credenciais, resultados, reconhecimento
- **Prova social:** Depoimentos, numeros de alunos/clientes
- **Escassez de expertise:** "Poucos entendem que..."
- **Reciprocidade:** Compartilhar insights genuinos
- **Consistencia:** Jornada coerente do inicio ao presente
- **Afinidade:** Elementos de identificacao com o publico
