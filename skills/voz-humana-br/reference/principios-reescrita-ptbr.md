# Princípios de Reescrita PT-BR

Guia positivo pra produzir prosa que lê como humana. Cada regra vem com exemplo antes/depois em português brasileiro.

---

## 1. Filosofia Central

Cada palavra escolhida com precisão, intenção e peso.

IA escreve pra encher espaço. Humano escreve pra comunicar. A diferença não é inteligência nem vocabulário. É economia impiedosa. Toda palavra tem que pagar o aluguel. Se a frase funciona sem a palavra, a palavra é desnecessária.

"Escrita vigorosa é concisa. A frase não deve ter palavra desnecessária, o parágrafo não deve ter frase desnecessária, pela mesma razão que um desenho não deve ter traço desnecessário e uma máquina não deve ter peça desnecessária." (Strunk, traduzido livre).

Isso não significa que toda frase tem que ser curta. Significa que toda palavra tem que trabalhar.

## 2. Ritmo de Frase

### O Princípio Provost (versão PT-BR)

> "Essa frase tem cinco palavras. Aqui vão mais cinco. Frase de cinco palavras funciona. Mas várias seguidas ficam monótonas. Escuta o que tá acontecendo. O texto cansa. O som dele arrasta. Parece disco arranhado. O ouvido pede variedade. Agora escuta. Eu varia o tamanho da frase, e aí crio música. Música. O texto canta. Tem balanço, tem ritmo, tem leveza. Uso frases curtas. Uso frases de tamanho médio. E às vezes, quando já sei que o leitor tá descansado, eu pego ele com uma frase de tamanho considerável, uma frase que arde com energia, que ganha impulso como um crescendo, com batida de tambor, com prato estalando, com som que grita: presta atenção aqui, isso é importante."

### Alvos quantitativos

- **Não-ficção:** desvio padrão de ~6 palavras por frase (faixa entre 8 e 26 palavras)
- **Ficção:** desvio padrão de ~9 a 11 palavras por frase (faixa 3 a 35)
- **Default IA que a gente quer evitar:** desvio padrão de ~2 a 3 (quase toda frase entre 15 e 20 palavras)

**Limiar mínimo:** se o SD do tamanho de frase num parágrafo é menor que 5, reescreve.

### O padrão 1-1-3

Depois de duas frases curtas (menos de 8 palavras), dispara uma longa (25 a 35 palavras). Aí quebra o padrão. Nunca deixa o próprio padrão virar previsível.

### Distribuição alvo por parágrafo

| Tamanho da frase | % ideal de frases |
|---|---|
| 1 a 5 palavras | 10 a 15% |
| 6 a 14 palavras | 30 a 40% |
| 15 a 22 palavras | 30 a 35% |
| 23+ palavras | 15 a 20% |

### Técnicas específicas pra ritmo

1. **Fragmento pra ênfase.** Profissional usa fragmento de propósito. Não por acaso. De propósito.
2. **Compound-complex depois de duas curtas.** Curta. Curta. Aí uma frase que leva o leitor por uma oração subordinada, pega uma observação entre vírgulas e aterrissa no ponto principal com impulso.
3. **Interrompe a si mesmo com ponto.** Cria a espontaneidade do pensamento real.
4. **Usa os dois-pontos pra punchline:** O resultado foi claro: falha.
5. **Faz uma pergunta no meio do parágrafo.** Por quê? Porque IA quase nunca faz.
6. **Lista dentro da frase** quando tem três itens ou mais, em vez de cada um esticado numa oração paralela.

### Antes (padrão IA):
> O time de pesquisa descobriu várias descobertas importantes durante o estudo. Eles analisaram os dados usando métodos estatísticos avançados cuidadosamente. Os resultados mostraram melhora significativa em todas as categorias medidas. As implicações dessas descobertas são substanciais pro campo.

Quatro frases: 12, 10, 11, 11 palavras. SD = 0,8. Monotonia que mata.

### Depois (padrão humano):
> O time encontrou algo. Não um resultadinho qualquer enterrado no ruído, mas um sinal limpo em todas as categorias que eles mediram. Tinham usado métodos estatísticos padrão, nada exótico, o que deixava a consistência ainda mais impressionante. Importou.

Tamanhos: 4, 22, 20, 1. SD ≈ 10. Vivo.

### Teste do "lê em voz alta"

Se toda frase puxa a mesma respiração, reescreve. Fala humana natural alterna surto rápido com corrida sustentada.

## 3. Escolha da Palavra

### Preferência Simples vs Latina em PT-BR

Em português a régua é a mesma: palavra curta e comum vence palavra longa e acadêmica.

| Latino inflado | Simples |
|---|---|
| iniciar | começar |
| finalizar | terminar, acabar |
| auxiliar | ajudar |
| adquirir | comprar, conseguir |
| suficiente | bastante, que dá |
| indagar | perguntar |
| residir | morar |
| transpirar | suar |
| falecido | morto |
| fabricar | fazer, construir |
| utilizar | usar |
| demonstrar | mostrar |
| empenhar-se | tentar |
| necessitar | precisar |
| facilitar | ajudar |
| elucidar | explicar |
| averiguar | descobrir |
| constituir | formar, ser |

Não é absoluto. "Investigar" vence "olhar mais fundo" num relatório técnico. Mas a preferência deve puxar pra simples, a não ser que a formalidade seja exigida pelo contexto.

### Teste do "Eu falaria isso em voz alta?"

Pergunta: "Eu diria essa palavra em voz alta pra um cliente numa reunião?" Se não, troca.

| Inflado (IA) | Preciso (humano) |
|---|---|
| "utilizar" | "usar" |
| "realizar" | "fazer" |
| "comprovar" | "provar" |
| "subsequentemente" | "depois" ou "em seguida" |
| "aproximadamente" | "mais ou menos" ou "uns" |
| "demonstrar" | "mostrar" |
| "necessitar" | "precisar" |
| "facilitar" | "ajudar" |
| "esclarecer" (quando substitui explicar) | "explicar" |
| "averiguar" | "descobrir" ou "checar" |
| "constitui" | "é" ou "forma" |
| "no que tange a" | "sobre" |
| "no contexto de" | "em" ou "pra" |
| "uma ampla gama de" | "vários" ou nomeia os itens |
| "tem papel crucial" | nomeia o papel real |
| "serve como prova de" | "prova" ou "mostra" |

### De-nominalização

IA adora nominalizar: transforma verbo em substantivo abstrato. Isso enterra a ação e remove o ator.

**O fix:** acha o verbo escondido no substantivo. Faz ele ser o verbo principal. Nomeia quem fez.

| Nominalizado (IA) | De-nominalizado (humano) |
|---|---|
| "A implementação do sistema foi concluída" | "Implementamos o sistema" |
| "Uma investigação foi conduzida" | "Investigamos" |
| "Houve um aumento na participação" | "Mais gente participou" |
| "A avaliação dos resultados revelou..." | "Quando avaliamos os resultados, vimos..." |
| "Foi tomada a decisão de prosseguir" | "Decidimos seguir" |
| "Consideração deve ser dada a..." | "Considera..." |
| "Houve a formação de um comitê" | "Formaram um comitê" |
| "Foi alcançada uma redução de custos" | "Cortaram os custos" |
| "Há necessidade de melhoria" | "Precisa melhorar" |

**Regra de detecção:** sufixos de substantivo escondendo verbo: **-ção, -mento, -ância, -ência, -idade, -ismo, -agem**. Se a frase também tem "foi/era/é/são/houve/ocorreu", é quase certo nominalização pra matar.

## 4. Criação de Parágrafo

### 12 aberturas alternativas

IA abre parágrafo quase sempre com "O X...", "A Y...", "Isso é...", "[Tópico] é...". Nunca mais que 2 em 5 parágrafos consecutivos começando com "O/A/Esse/Isso".

1. **Verbo imperativo ou gerúndio:**
   "Pensa no que acontece quando..." / "Rodando os números de novo, apareceu..."

2. **Locução prepositiva:**
   "Por trás dos dados, um padrão apareceu." / "Depois de três tentativas que morreram, o time mudou de rota."

3. **Oração subordinada:**
   "Quando o resultado chegou, ninguém comemorou." / "Como o orçamento já tinha acabado, a gente improvisou."

4. **Citação ou diálogo:**
   "'Não pode tá certo', ela falou, rolando a planilha."

5. **Número ou estatística:**
   "Quarenta e três por cento desistiu na primeira semana."

6. **Contraste ou concessão:**
   "É verdade, o protótipo falhou. Mas falhou na direção certa."

7. **Pergunta:**
   "O que acontece se a gente dobrar a dose?"

8. **Advérbio ou locução adverbial:**
   "Silenciosamente, o setor mudou." / "Por três décadas ninguém questionou aquilo."

9. **Oração participial:**
   "Tirando o jargão, o argumento era simples." / "Depois de esgotar todas as alternativas, voltamos ao desenho original."

10. **Marcação temporal:**
    "Na quinta, o projeto morreu." / "Três anos depois, o paper foi retirado."

11. **Analogia ou imagem:**
    "Como sedimento que se acumula num rio, os erros foram se empilhando."

12. **Fragmento declarativo curto:**
    "Errado." / "Não exatamente." / "Beco sem saída."

### Variação de tamanho de parágrafo

Conteúdo dita tamanho. Parágrafo de uma frase pra ponto afiado. Parágrafo de dez pra argumento complexo. Nunca deixa todos em torno de 3 a 5 frases.

### Transição não é obrigatória

A melhor técnica de transição é não ter transição. Profissional começa a próxima ideia direto. A quebra de parágrafo já é a transição. IA sinaliza demais conexão que o leitor faria sozinho.

## 5. Regras Essenciais (Strunk e Zinsser adaptado PT-BR)

### "Omite palavra desnecessária"

Não significa que toda frase tem que ser curta. Significa que toda palavra tem que pagar o aluguel.

| Inflado | Direto |
|---|---|
| "a fim de" | "pra" |
| "em virtude de" | "por causa de" |
| "no presente momento" | "agora" |
| "é importante notar que" | (apaga e fala a coisa) |
| "uma série de" | "vários" ou número real |
| "no caso de" | "se" |
| "tem a capacidade de" | "pode" |
| "tomar uma decisão" | "decidir" |
| "conduzir uma investigação" | "investigar" |
| "dar consideração a" | "considerar" |
| "é indicativo de" | "indica" ou "mostra" |
| "pra fins de" | "pra" |

### Usa voz ativa

Nomeia o ator. Faz ele fazer a coisa. Voz passiva esconde quem fez e chupa energia.

| Passivo (IA) | Ativo (humano) |
|---|---|
| "O experimento foi conduzido pelo time" | "O time rodou o experimento" |
| "Foi determinado que os resultados foram significativos" | "Os resultados foram fortes" (ou: "A gente encontrou resultado forte") |
| "Erros foram cometidos" | "A gente errou" |

### Estado positivo em vez de negativo

| Negativo (IA) | Positivo (humano) |
|---|---|
| "Não era frequentemente pontual" | "Chegava atrasado sempre" |
| "Não lembrou" | "Esqueceu" |
| "Não prestou atenção" | "Ignorou" |
| "Não importante" | "Trivial" |
| "Não tinha muita confiança em" | "Desconfiava de" |

### Linguagem definida, específica, concreta

Vago é marca d'água de IA. Específico é marca d'água de quem sabe.

| Vago (IA) | Específico (humano) |
|---|---|
| "Um período de tempo ruim se instalou" | "Choveu todo dia por uma semana" |
| "Ele mostrou satisfação" | "Ele sorriu" (ou o que realmente fez) |
| "Muitos fatores contribuíram" | "Três coisas puxaram: o custo, o tempo e a oposição pública" |

### Declutter (inchaço) em PT-BR

> "Lutar contra inchaço é como capinar: o escritor tá sempre um pouco atrás."

| Inchado (IA) | Limpo (humano) |
|---|---|
| "facilitar" | "ajudar" |
| "indivíduo" (como substantivo) | "pessoa" |
| "suficiente" | "bastante" |
| "tentativa" | "tentar" |
| "numerosos" | "muitos" |
| "utilizar" | "usar" |
| "implementar" | "fazer", "começar", "criar" |
| "alavancar" | "usar" |
| "priorizar" | "focar em" |
| "otimizar" | "melhorar" |
| "metodologia" | "método" |
| "funcionalidade" | "função" ou nomeia o que faz |
| "abrangente" | (quase sempre apaga; se precisa, "completo") |

### Pensa pequeno

Decide qual cantinho do tema você vai cobrir e cobre bem. IA tenta cobrir tudo. Humano escolhe ângulo. Texto sobre "a história do café" deveria ser sobre UMA fazenda na Etiópia em 1952, ou sobre UM químico que isolou a cafeína, ou sobre como SUA avó fazia. Pequeno cria autoridade.

### Escreve pra uma pessoa

Não pra "o público" nem pra "os leitores". Pra alguém específico. Imagina uma amiga inteligente sentada na sua frente. Escreve pra ela.

### Regras base

1. **Revisa sem dó.** Primeiro rascunho tem gordura. Corta 30 a 50% na revisão.
2. **Verbo ativo, não passivo.** Ativo empurra o texto. Passivo deixa cair.
3. **Tira advérbio que o verbo já carrega.** "Ela sorriu alegremente" vira "ela sorriu". Se o sorriso não é alegre, escolhe outro verbo: "ela abriu um sorriso torto".
4. **Seja você.** Não tem loja de estilo. Estilo é orgânico à pessoa que escreve.

## 6. Transições Naturais

### A blacklist

Proibida como abertura de parágrafo ou frase (ver `palavras-proibidas-ptbr.md` pra lista completa):
Ademais, Outrossim, Adicionalmente, Destarte, Doravante, Notadamente, Por conseguinte, Consequentemente (no início), Em conclusão, Em resumo, Em suma.

### O que humano brasileiro usa de verdade

**Pra adição:**
- "E" (sim, pode começar frase com "e")
- "Também" (no meio da frase, não como abertura isolada)
- "Fora isso"
- "Ainda"
- "Tem mais"
- Nenhuma transição. Põe a próxima ideia depois da anterior. Leitor infere.

**Pra contraste:**
- "Mas" (começar frase com "mas" é natural)
- "Só que"
- "Agora"
- "Aí"
- "Acontece que"
- "Ainda assim"
- "Mesmo assim"
- "Por outro lado" (com cautela, evita virar tique)
- "O problema é que..."
- "Só que não funcionou."

**Pra causa/efeito:**
- "Então" (o conector mais natural em PT-BR)
- "Por isso..."
- "Aí..."
- "Daí..."
- "Resultado:"
- "E isso significa..."
- "Isso quebrou tudo."

**Pra exemplo:**
- "Pega [caso específico]."
- "Olha isso:"
- "Imagina que você é..."
- "[Nome] descobriu isso do jeito difícil."
- "Pensa numa cliente minha."

**Pra ênfase:**
- "O ponto é..."
- "O que importa aqui:"
- "Isso que a maioria não percebe."
- Repetir palavra-chave do parágrafo anterior.

### A melhor técnica de transição

Nenhuma. A quebra de parágrafo já é a transição. IA avisa demais conexão que o leitor enxergaria sozinho.

### Antes (IA):
> Ademais, a pesquisa adicionalmente revelou que participantes que se exercitaram regularmente mostraram melhora. Outrossim, essas melhoras foram notadamente consistentes em todas as faixas etárias. Consequentemente, o time concluiu que o exercício é, de fato, benéfico.

### Depois (humano):
> Quem se exercitou melhorou. Todas as idades, mesmo padrão. O time achava que idade ia importar. Não importou.

## 7. Régua de Match de Registro

Combina o nível de formalidade do input. Não impõe voz.

- Input casual → output casual. Usa contração, gíria, frase curta.
- Input acadêmico → output acadêmico. Frase mais longa é ok. Termo técnico é ok. Mas as palavras banidas continuam banidas.
- Input profissional de negócio → mesmo registro. Claro, direto, confiante. Sem buzzword.
- Input criativo/literário → mais liberdade estilística. Fragmento, imagem, subtexto.

**Regra-chave:** a reescrita tem que soar como escrita pela mesma pessoa do input, só que melhor. Nunca converte casual em formal nem o contrário.

**Preserva o que já é humano:** se o original tem opinião, humor, anedota pessoal, tangente, sentimento misto, ou incerteza, essas são as partes mais valiosas. É exatamente o que separa texto humano de saída de máquina. Protege com unhas e dentes. Humanizar significa tirar a camada de máquina pra revelar a pessoa por baixo, não substituir uma voz por outra. Se a mentorada fala "eu não paro de pensar nisso" ou "olha, me incomoda bastante", é ouro. Mantém.

## 8. Os 10 Mandamentos da Prosa Anti-IA

1. **Varia tamanho de frase sem dó.** Mira SD de 6+ palavras. Mistura soco de 3 palavras com corrida de 30.
2. **Mata nominalização.** Acha o verbo escondido no substantivo. Usa ele.
3. **Escolhe a palavra curta.** "Usar" não "utilizar". "Ajudar" não "facilitar". Simples vence latino.
4. **Apaga transição.** Se o leitor acompanha sem "ademais", corta "ademais".
5. **Varia abertura de parágrafo.** Monitora primeiras palavras. Força variedade.
6. **Omite palavra desnecessária.** Aí omite mais. Se a frase funciona sem a palavra, a palavra é desnecessária.
7. **Voz ativa por default.** Nomeia o ator. Faz ele fazer a coisa.
8. **Palavra mais forte no fim da frase.** Última posição carrega mais peso.
9. **Quebra regra de propósito.** Fragmento. Começa com "E". Termina com preposição. Uma quebra deliberada por página assina mão humana.
10. **Nunca usa palavra da blacklist.** Nem uma vez. Elas tão queimadas. Acha outro jeito.

## 9. O Filtro Copy-editor em 9 Passos

Roda esse checklist em toda reescrita antes de entregar.

### Passo 1 — Lê em voz alta
Marca toda frase onde sua voz cai em monotom. Reescreve essas.

### Passo 2 — Circula primeiras palavras
Circula a primeira palavra de toda frase. Se mais de 30% começa com "O", "A", "Esse", "Isso" ou nome próprio, reescreve aberturas.

### Passo 3 — Marca todas as transições
Apaga metade. As conexões restantes devem ser implícitas.

### Passo 4 — Acha toda frase com 20+ palavras
Dá pra quebrar? Deveria?

### Passo 5 — Acha toda frase com menos de 8 palavras
Ela soca? Ou é só curta à toa?

### Passo 6 — Busca palavra da blacklist
Substitui cada uma. Sem exceção. Ver `palavras-proibidas-ptbr.md`.

### Passo 7 — Conta parágrafos
Se têm todos o mesmo tamanho, junta alguns e quebra outros.

### Passo 8 — Acha a opinião do autor
Se não tem opinião em lugar nenhum, adiciona uma. Humano tem opinião. IA hedge.

### Passo 9 — Teste do "primeiro resultado do Google"
Pergunta: "O que o leitor aprende aqui que ele não pegaria no primeiro resultado do Google?" Se nada, o texto precisa de ângulo, dado específico, experiência.

## 10. Framework de Score Stop-Slop

Dá nota 1-10 em cada dimensão. Abaixo de 35/50, reescreve.

| Dimensão | O que mede | Guia de nota |
|---|---|---|
| **Diretividade** | Chega no ponto sem pigarro? | 10 = primeira frase é o ponto. 1 = três parágrafos de setup antes do ponto. |
| **Ritmo** | Tamanho varia natural? | 10 = SD maior que 7, faixa ampla. 1 = toda frase 15 a 20 palavras. |
| **Confiança** | Respeita inteligência do leitor? | 10 = zero meta-comentário, zero conclusão repetida. 1 = explica cada ponto duas vezes. |
| **Autenticidade** | Soa como pessoa específica? | 10 = voz distinta, opinião, específico. 1 = poderia ser qualquer IA. |
| **Densidade** | Cada palavra é necessária? | 10 = não dá pra cortar nada. 1 = 50% dá pra apagar sem perder informação. |

## 11. Appendix — Fixes Rápidos Frase-a-Frase

| Padrão IA | Fix humano |
|---|---|
| Toda frase entre 15 e 20 palavras | Mistura fragmento de 3 com frase complexa de 30 |
| Voz passiva default | Nomeia o ator. Ativa. |
| Sem contração | Usa "tá", "pra", "dá", "cê" no tom certo |
| Sem "e" ou "mas" começando frase | Começa algumas com "E" ou "Mas" |
| Sem fragmento | Usa fragmento pra ênfase. "Jamais." "Fim." |
| Verbo inflado ("serve como", "facilita") | Verbo simples: "é", "tem", "ajuda", "mostra" |
| Vago ("muitos estudos", "melhora significativa") | Específico: "Três estudos em 2024." "Aumento de 25%." |
| Sem detalhe sensorial | Adiciona o que você viu, ouviu, sentiu |

## 12. Appendix — Fixes Rápidos de Voz

| Padrão IA | Fix humano |
|---|---|
| Sem experiência pessoal | Adiciona anedota específica só você saberia |
| Sem incerteza real | "Não tenho certeza" é humano. "É importante notar" é IA. |
| Sem sentimento misto | "Gostei da interface, mas o onboarding me confundiu" |
| Sem humor ou ironia | Humor seco ainda assina mão humana |
| Sem tangente | Aside breve que conecta a experiência real |
| Sem opinião | Toma partido. Discorda da sabedoria comum. Compromete. |
| Emocionalmente plano apesar de vocabulário emocional | Detalhe sensorial concreto em vez de palavra abstrata |
| Sem reflexão metacognitiva | "Mudei de ideia sobre isso", "eu achava X mas agora..." |
