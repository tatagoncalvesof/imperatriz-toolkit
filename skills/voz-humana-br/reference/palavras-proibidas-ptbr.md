# Dicionário de Palavras Proibidas PT-BR

Cada palavra aqui aparece 5 a 200 vezes mais em texto de IA do que em texto de humano escrevendo em português brasileiro. Lista fechada: se a palavra tá aqui, troca. Se não tá, tá liberada.

## Seção 2 — Palavras Amarelas (Máximo 1 por documento)

Palavras reais em português, mas IA usa 5 a 10 vezes mais que humano. Máximo 1 vez por texto.

- abrangente
- significativo
- crucial
- essencial
- fundamental
- dinâmico
- inovador
- estratégico
- transformador
- impactante
- robusto
- potencial (como substantivo: "o potencial de")
- jornada (se for pra usar mesmo, uma vez, e contexto físico de viagem ou cronológico)

**Regra:** Se a palavra aparece no input mais de uma vez, substitui todas menos uma. Mantém a que for mais precisa.

## Seção 3 — Tabela de Camuflagem de Cópula

IA sistematicamente troca "é/está/tem" por verbos inflados. Sempre volta ao simples.

| IA prefere | Humano escreve |
|---|---|
| serve como um | é um |
| se apresenta como um | é um |
| se configura como | é |
| se estabelece como | é, virou |
| se consolida como | é, virou |
| marca um | é um |
| representa um | é um |
| constitui um | é um |
| ostenta | tem |
| apresenta (no sentido de ter) | tem |
| oferece (no sentido de possuir) | tem |
| dispõe de | tem |
| exibe | mostra, tem |
| conta com | tem |
| abriga | tem, guarda |
| comporta | tem, cabe |
| encarna | é |
| incorpora | tem, inclui |

**Regra de detecção:** Busca por "serve como", "se apresenta", "marca um", "representa um", "constitui", "ostenta", "dispõe de", "conta com" (em contextos não estritamente necessários). Se dá pra trocar por "é/tem" sem perder sentido, troca.

## Seção 5 — Nominalização (Verbos Escondidos em Substantivos)

Em PT-BR a regra é a mesma: IA adora esconder o verbo dentro de substantivo abstrato. Libera o verbo.

### Regra de detecção

Procura substantivos terminados em **-ção, -mento, -ância, -ência, -idade, -ismo, -agem**. Se a frase também tem "foi/era/é/são/houve/ocorreu/se deu", quase certo tem nominalização pra matar.

### Exemplos antes/depois

| Nominalizado (IA) | De-nominalizado (Humano) |
|---|---|
| "A implementação do sistema foi concluída" | "Implementamos o sistema" |
| "Foi realizada uma investigação" | "Investigamos" |
| "Houve um aumento na participação" | "Mais gente participou" |
| "A avaliação dos resultados revelou" | "Quando avaliamos os resultados, vimos" |
| "Foi tomada a decisão de prosseguir" | "Decidimos seguir" |
| "Deve-se dar consideração a" | "Considera" / "Leva em conta" |
| "Houve o estabelecimento de um comitê" | "Formaram um comitê" |
| "Foi alcançada uma redução nos custos" | "Cortaram os custos" |
| "Há necessidade de melhoria" | "Precisa melhorar" |
| "A aplicação de pressão resultou em" | "A pressão causou" |
| "A realização do evento ocorreu em" | "O evento foi em" |
| "A execução do projeto se deu" | "Rodamos o projeto" |
| "A obtenção do resultado foi" | "Conseguimos o resultado" |
| "O desenvolvimento da solução" | "Desenvolver a solução" / "Criar a solução" |

## Seção 8 — Pontuação que Delata IA

Não é palavra, mas conta. Check final sempre:

| Pontuação | Regra |
|---|---|
| Travessão longo (—) | Máximo 1 a cada 500 palavras, e só se é quebra real de pensamento |
| Travessão como aposição | Troca por vírgula ou parênteses |
| Dois-pontos excessivos | Máximo 5 em texto de 300 palavras |
| Negrito dentro de parágrafo | Zero em prosa corrente. Negrito só em título ou label de UI |
| Itálico em toda palavra-chave | Reserva pra estrangeirismo, citação, título de obra |
| Aspas curvas "" | OK se já vieram; humano digita `"` reto no mobile |
| Emoji no início de bullet | Zero em texto profissional |
| Emoji enquadrando título | Zero |
| Emoji a cada frase | Máximo 1 a cada 3 parágrafos em canal casual; zero em canal formal |
| Reticências (…) como suspiro | Máximo 1 por texto |
| Maiúscula de ênfase (PALAVRA) | Máximo 1 por texto, e só em canal casual |
