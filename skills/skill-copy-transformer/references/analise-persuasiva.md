# Framework de Analise Persuasiva — 9 Dimensoes

Apos transformar a copy em template, realizar esta analise obrigatoria para revelar a engenharia persuasiva por tras da copy.

## Dimensao 1: Analogias e Objecoes

**O que analisar:**
- Quais analogias a copy usa para simplificar conceitos complexos?
- Quais objecoes do publico sao abordadas diretamente?
- Quais objecoes sao abordadas indiretamente (sem mencionar explicitamente)?
- Como a copy antecipa e neutraliza resistencias?

**Template de saida:**
```
ANALOGIAS ENCONTRADAS:
- "[Analogia 1]" → Simplifica [conceito] usando [comparacao]
- "[Analogia 2]" → Simplifica [conceito] usando [comparacao]

OBJECOES ABORDADAS:
- Objecao: "[texto]" → Abordagem: [como a copy neutraliza]
- Objecao: "[texto]" → Abordagem: [como a copy neutraliza]

OBJECOES NAO ABORDADAS (oportunidade):
- [Objecao que poderia ser incluida]
```

## Dimensao 2: Crencas, Problemas e Solucoes

**O que analisar:**
- Quais crencas a copy tenta INSTALAR no leitor?
- Quais crencas a copy tenta MODIFICAR ou DESTRUIR?
- Quais problemas sao destacados (e em que ordem)?
- Quais solucoes sao propostas?
- Qual a relacao problema → solucao → crenca?

**Template de saida:**
```
CRENCAS INSTALADAS:
1. "[Nova crenca que a copy quer que o leitor adote]"
2. "[Nova crenca]"

CRENCAS DESTRUIDAS:
1. "[Crenca antiga]" → Substituida por "[Nova crenca]"
2. "[Crenca antiga]" → Substituida por "[Nova crenca]"

CADEIA PROBLEMA-SOLUCAO:
Problema 1: [X] → Solucao: [Y] → Crenca resultante: [Z]
```

## Dimensao 3: Transformacao e Beneficio Principal

**O que analisar:**
- Qual e a transformacao CENTRAL prometida?
- Qual o beneficio PRINCIPAL (o que move a decisao)?
- Qual o ANTES e DEPOIS implicito?
- Como a copy valoriza e amplifica o impacto?

**Template de saida:**
```
TRANSFORMACAO CENTRAL:
De: [estado atual/dor] → Para: [estado desejado/resultado]

BENEFICIO PRINCIPAL:
[O beneficio que, sozinho, justifica a acao]

HIERARQUIA DE BENEFICIOS:
1. [Beneficio principal] (racional/emocional)
2. [Beneficio secundario]
3. [Beneficio terciario]
```

## Dimensao 4: Publico-Alvo e Psicografia

**O que analisar:**
- Quem e o publico-alvo (demografia basica)?
- Quais caracteristicas psicograficas sao reveladas (valores, crencas, estilo de vida)?
- Como a copy "fala a lingua" desse publico?
- Qual nivel de consciencia o publico esta (desconhece o problema, conhece o problema, conhece solucoes, conhece voce)?

**Template de saida:**
```
PERFIL DEMOGRAFICO IMPLICITO:
- Idade provavel: [X]
- Genero: [X]
- Renda: [X]
- Profissao: [X]

PERFIL PSICOGRAFICO:
- Valores: [O que importa pra eles]
- Medos: [O que temem]
- Aspiracoes: [O que sonham]
- Frustrações: [O que os irrita]
- Estilo de vida: [Como vivem]

NIVEL DE CONSCIENCIA (Eugene Schwartz):
[1-Desconhece | 2-Consciente do problema | 3-Consciente da solucao | 4-Consciente do produto | 5-Mais consciente]
```

## Dimensao 5: Metodologia e Mecanismo Unico

**O que analisar:**
- Qual e a metodologia/sistema/processo apresentado?
- Quais sao os pilares ou etapas?
- O que torna esta abordagem DIFERENTE de tudo que ja existe?
- Qual e o "mecanismo unico" (a razao pela qual funciona)?

**Template de saida:**
```
METODOLOGIA:
Nome: [Se tem nome proprio]
Pilares/Etapas:
1. [Pilar 1]
2. [Pilar 2]
3. [Pilar 3]

MECANISMO UNICO:
"Funciona porque [explicacao do diferencial]"

POSICIONAMENTO vs. CONCORRENCIA:
Outros fazem [X]. Nos fazemos [Y]. A diferenca e [Z].
```

## Dimensao 6: Historias, Desafios e Depoimentos

**O que analisar:**
- Quais narrativas de sucesso sao contadas?
- Quais desafios superados sao mencionados?
- Ha depoimentos ou provas sociais?
- Como essas historias reforçam a credibilidade?

**Template de saida:**
```
HISTORIAS PRESENTES:
1. [Historia] → Proposito: [O que ela prova/inspira]
2. [Historia] → Proposito: [O que ela prova/inspira]

DESAFIOS SUPERADOS:
- [Desafio] → Como foi superado: [Resolucao]

PROVAS SOCIAIS:
- [Tipo] → Impacto: [Forte/Medio/Fraco]

CREDIBILIDADE GERAL: [Alta/Media/Baixa] — Porque: [Justificativa]
```

## Dimensao 7: Problemas Atuais, Armadilhas e Mitos

**O que analisar:**
- Quais problemas ATUAIS do mercado a copy aborda?
- Quais armadilhas comuns ela alerta?
- Quais mitos ou crencas falsas ela desmascara?
- Como isso educa o publico e cria autoridade?

**Template de saida:**
```
PROBLEMAS DO MERCADO ABORDADOS:
1. [Problema atual] → Posicao da copy: [Como aborda]

ARMADILHAS ALERTADAS:
1. [Armadilha] → "Cuidado com [X] porque [Y]"

MITOS DESMASCARADOS:
1. Mito: "[Crenca falsa]" → Verdade: "[Realidade apresentada]"
```

## Dimensao 8: Conscientizacao e Mensagens-Chave

**O que analisar:**
- Qual e o esforço da copy para aumentar a consciencia do problema?
- Quais sao as 3-5 mensagens CENTRAIS comunicadas?
- Em que ordem as mensagens aparecem (e por que essa ordem)?
- Qual a mensagem que o leitor LEMBRA depois de ler?

**Template de saida:**
```
JORNADA DE CONSCIENTIZACAO:
1. [Primeiro ponto de consciencia criado]
2. [Segundo ponto]
3. [Terceiro ponto]

MENSAGENS-CHAVE (em ordem de impacto):
1. "[Mensagem mais importante]"
2. "[Segunda mensagem]"
3. "[Terceira mensagem]"

MENSAGEM RESIDUAL (o que fica na mente):
"[A unica frase que o leitor lembra dias depois]"
```

## Dimensao 9: Empatia e Sentimento

**O que analisar:**
- Qual o tom emocional predominante (medo, esperanca, urgencia, inspiracao)?
- Como a copy constroi empatia com o leitor?
- Qual a jornada emocional (inicio → meio → fim)?
- Mapa de empatia: O que o leitor PENSA, SENTE, VE, OUVE?

**Template de saida:**
```
TOM EMOCIONAL PREDOMINANTE: [Medo/Esperanca/Urgencia/Inspiracao/Empoderamento]

JORNADA EMOCIONAL:
Inicio: [Emocao] → Meio: [Emocao] → Fim: [Emocao]
Ex: Dor → Esperanca → Urgencia de agir

MAPA DE EMPATIA:
┌─────────────────────────────────────┐
│ PENSA: [O que passa na mente]       │
│ SENTE: [Emocoes dominantes]         │
│ VE: [O que observa no ambiente]     │
│ OUVE: [O que ouve de outros]        │
│ FAZ: [Acoes que toma]               │
│ DORES: [Frustrações principais]     │
│ GANHOS: [O que deseja ganhar]       │
└─────────────────────────────────────┘

ANALISE DE SENTIMENTO:
- Polaridade geral: [Positiva/Negativa/Mista]
- Intensidade: [Alta/Media/Baixa]
- Gatilhos emocionais usados: [Lista]
```

## SINTESE FINAL (Obrigatoria)

Integrar TODAS as 9 dimensoes em um paragrafo de sintese que mostra:
1. Como os elementos se entrelaçam
2. Qual a "engenharia emocional" por tras da copy
3. Pontos fortes da copy
4. Oportunidades de melhoria
5. Por que essa copy funciona (ou nao) para o publico-alvo
