# Pilar 01 — Narrativa Fundacional (Etapas 1-5)

Constroi a base emocional, a identificacao e a previsibilidade do Pitch High-Ticket.

## Objetivo

Transformar Blueprint + Oferta + Historia do Metodo em script completo e validado das etapas 1-5:
1. O Porque (Causa)
2. Para quem e / nao e
3. Por que agora
4. Tempo para resultado
5. Entregaveis (modulo + beneficio)

---

## Entradas Necessarias

- **Blueprint do Negocio** — Posicionamento, persona, concorrencia, promessas
- **Oferta** — Nome do programa, preco, condicoes, bonus, garantias
- **Historia do Metodo** — Origem, viradas, provas, resultados

O agente usa essas entradas para diagnosticar lacunas, preencher variaveis e roteirizar as 5 etapas com profundidade.

## Saidas deste Pilar

- Script pronto (texto final) das etapas 1-5
- Mapa de Lacunas (score 0-5) por etapa, com sugestoes de correcao
- Resumo executivo com bullets "pontos fortes / pontos a reforcar"
- Check de coerencia (promessa, tempo e entregaveis alinhados)

## Modo de Execucao

1. **Diagnosticar** — Le entradas, atribui score, identifica faltas
2. **Construir** — Gera versoes V1 de cada etapa
3. **Refinar** — Aplica checklist de qualidade + ajuste de tom/voz
4. **Validar** — Pausas rapidas de aprovacao antes de seguir

---

## Etapa 1 — O PORQUE (A CAUSA)

### Diagnostico Rapido (score 0-5)

- Existe uma missao maior que dinheiro?
- A causa desassocia o papel de "vendedor" e conecta com a audiencia?
- Ha prova/episodio que sustente a causa (origem do metodo)?

### Coleta Dirigida

- Por que este programa existe?
- Qual injustica/lacuna do mercado voce combate?
- Quem voce quer servir e por que?

### Template de Script

```
"Antes de falar do programa, eu preciso te contar por que eu criei isso.
Eu vi {{ProblemaLatente}}, e entendi que {{InsightTransformador}}.
A minha causa e {{CausaMaior}}: {{ImpactoDesejado}}.
Nao se trata so de vender; {{CompromissoComPessoas}}."
```

### Variaveis

| Variavel | Descricao | Fonte |
|----------|----------|-------|
| `{{ProblemaLatente}}` | Problema que o mercado ignora ou resolve mal | Blueprint: dor do avatar |
| `{{InsightTransformador}}` | Percepcao unica que originou o metodo | Historia: momento eureka |
| `{{CausaMaior}}` | Missao que transcende o produto | Historia: motivacao pessoal |
| `{{ImpactoDesejado}}` | Mudanca que quer causar no mundo | Blueprint: visao |
| `{{CompromissoComPessoas}}` | Promessa pessoal ao publico | Historia: compromisso |

### Checklist de Qualidade

- [ ] Claro, concreto e nao autocentrado
- [ ] Narrativa curta (30-60s) com 1 exemplo vivo
- [ ] Teste "espinha": se remover o produto, a causa permanece?
- [ ] Tom: vulnerabilidade controlada + autoridade

### Pausa de Validacao 1

Aprova a Causa? (Sim / Ajustar) → Se ajustar, reescrever 2 variacoes.

## Etapa 2 — PARA QUEM E / NAO E

### Diagnostico Rapido (score 0-5)

- Avatar claro (perfil, valores, desejos, contexto)?
- Exclusao explicita (nao e para...) para qualificar audiencia?
- Usa dados de pesquisas/respostas reais?

### Coleta Dirigida

- E para: `{{PerfilIdeal}}`, `{{Valores}}`, `{{Desejos}}`, `{{Contexto}}`
- Nao e para: `{{Desalinhados}}`, `{{Restricoes}}`, `{{Antivalores}}`

### Template de Script

```
"Este programa e para {{PerfilIdeal}}, que valorizam {{Valores}} e desejam
{{Desejos}}.
Nao e para quem {{NaoEPara}}. Eu quero pessoas {{QualidadesDesejadas}}."
```

### Variaveis

| Variavel | Descricao | Fonte |
|----------|----------|-------|
| `{{PerfilIdeal}}` | Quem e o cliente ideal (demografico + psicografico) | Blueprint: persona |
| `{{Valores}}` | O que essa pessoa valoriza | Blueprint: valores do avatar |
| `{{Desejos}}` | O que essa pessoa quer conquistar | Blueprint: desejos |
| `{{NaoEPara}}` | Comportamentos/perfis que excluimos | Blueprint: anti-avatar |
| `{{QualidadesDesejadas}}` | Atitudes que buscamos nos clientes | Blueprint: perfil ideal |

### Checklist de Qualidade

- [ ] 1-2 paragrafos; concreto (sem genericos)
- [ ] Evita rotulos agressivos; firmeza respeitosa
- [ ] "Leitura do espelho": avatar se reconhece em 5s?
- [ ] Exclusao qualifica sem ofender

### Pausa de Validacao 2

Aprova o Para quem e / nao e? (Sim / Ajustar) → 2 variacoes rapidas se ajustar.

## Etapa 3 — POR QUE AGORA

### Diagnostico Rapido (score 0-5)

- Mostra que "o melhor momento passou", mas quebra retrovisor?
- Custo de adiar explicito (financeiro, emocional, oportunidade)?
- Convida a decisao presente sem pressao incoerente?

### Coleta Dirigida

- Perdas atuais por adiar: `{{PerdasQuant}}`, `{{PerdasQuali}}`
- Ganhos se agir agora: `{{GanhosImediatos}}`, `{{PontoDePartidaSimples}}`

### Template de Script

```
"O melhor momento teria sido antes — mas ficou para tras.
Cada dia sem {{TransformacaoDesejada}} custa {{CustoDeAdiar}}.
Agora e quando voce para de perder {{PerdasChave}} e comeca
{{PrimeiroPassoPratico}}."
```

### Variaveis

| Variavel | Descricao | Fonte |
|----------|----------|-------|
| `{{TransformacaoDesejada}}` | O que o avatar quer alcançar | Blueprint: promessa |
| `{{CustoDeAdiar}}` | Quanto perde por mes/ano nao agindo | Oferta: calculo de perda |
| `{{PerdasChave}}` | Principais perdas concretas | Blueprint: dores |
| `{{PrimeiroPassoPratico}}` | Acao simples e imediata que pode tomar | Oferta: quick win |

### Checklist de Qualidade

- [ ] Nao culpar o publico; conscientizar
- [ ] 1 metrica concreta (ex.: R$ / tempo / chance)
- [ ] Fecho com convite (nao ultimato)
- [ ] Urgencia real, nao fabricada

### Pausa de Validacao 3

Aprova o Por que agora? (Sim / Ajustar) → Reescrever com 1 metrica alternativa.

## Etapa 4 — TEMPO PARA RESULTADO

### Diagnostico Rapido (score 0-5)

- Tempo medio com margem para cima/baixo?
- Coerencia com dados reais (pesquisas, cases)?
- Linguagem realista: "todas que aplicam chegam"

### Coleta Dirigida

- Media: `{{TempoMedio}}` (ex.: 6 meses)
- Faixa: `{{Min}}` a `{{Max}}` (ex.: 1-12 meses)
- Condicao: "Aplicando o metodo `{{Condicoes}}`"

### Template de Script

```
"Pelos nossos dados, o tempo medio para {{Marco}} e {{TempoMedio}}.
Ha quem chegue em {{Min}}, outros em {{Max}}.
Verdade: quem aplica o metodo {{Condicoes}} chega la."
```

### Variaveis

| Variavel | Descricao | Fonte |
|----------|----------|-------|
| `{{Marco}}` | Resultado principal mensuravel | Oferta: promessa principal |
| `{{TempoMedio}}` | Prazo medio real de resultado | Blueprint: dados de alunos |
| `{{Min}}` | Tempo minimo (caso rapido) | Blueprint: melhor case |
| `{{Max}}` | Tempo maximo (caso lento) | Blueprint: caso mais lento |
| `{{Condicoes}}` | O que precisa fazer para chegar | Blueprint: pre-requisitos |

### Checklist de Qualidade

- [ ] Inclui media + faixa; evita promessas absolutas
- [ ] Sem "milagre"; foco em processo
- [ ] Atratividade + credibilidade balanceadas
- [ ] Condicionado a aplicacao do metodo

### Pausa de Validacao 4

Aprova o Tempo para resultado? (Sim / Ajustar) → Trocar exemplos e clarificar condicoes.

## Etapa 5 — ENTREGAVEIS DO TREINAMENTO (Modulo + Beneficio)

### Diagnostico Rapido (score 0-5)

- Lista todos os modulos?
- Para cada modulo, explicita beneficio na vida (nao so conteudo)?
- Faz a pessoa se imaginar vivendo o resultado?

### Coleta Dirigida

Estruturar cada item assim:
- Modulo `{{#}}` — `{{NomeDoModulo}}`
  - Voce vai aprender: `{{ConteudoChave}}`
  - Para obter: `{{BeneficioConcretoNaVida}}` (ex.: economia, velocidade, autonomia)

### Template de Script

```
"Modulo 1 — {{Nome1}}: voce vai aprender {{Conteudo1}} para {{Beneficio1}}.
Modulo 2 — {{Nome2}}: voce vai aprender {{Conteudo2}} para {{Beneficio2}}.
Modulo 3 — {{Nome3}}: voce vai aprender {{Conteudo3}} para {{Beneficio3}}."
(Repetir para todos os modulos e bonus pedagogicos, se houver.)
```

### Checklist de Qualidade

- [ ] Nunca listar "solto": modulo + beneficio lado a lado
- [ ] Beneficios visuais (a pessoa se ve usando)
- [ ] Evitar jargao; linguagem do publico
- [ ] Conectar cada modulo a uma dor/desejo especifico

### Pausa de Validacao 5

Aprova os Entregaveis? (Sim / Ajustar) → Reordenar, fundir ou expandir modulos.
