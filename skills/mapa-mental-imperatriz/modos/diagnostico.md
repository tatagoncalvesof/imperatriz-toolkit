# Modo: DIAGNÓSTICO

## Quando usar

- "Por que não está funcionando?"
- Mentorada travada com problema
- Falha em campanha/lançamento/produto
- Análise de causa raiz
- Sintoma que precisa virar diagnóstico

## Estratégia

Mapa de diagnóstico é uma **árvore de causa raiz invertida**. Sintoma no topo (root), causas se ramificando, ações nas folhas.

3 movimentos:

1. **Sintoma claro** (o que está acontecendo?)
2. **Causas possíveis** (por quê? — agrupadas em pilares)
3. **Ações corretivas** (o que fazer pra cada causa)

## Hierarquia base

```
NÍVEL 0: Sintoma/problema (frase-curta)
NÍVEL 1: Pilares de causa (4-6 áreas)
NÍVEL 2: Causas específicas
NÍVEL 3: Ações corretivas (1 por causa)
```

## Pilares de causa (use como ponto de partida)

Adapte ao contexto. Pra negócios, comece com:

1. **Oferta** — o que está sendo vendido faz sentido?
2. **Tráfego** — está chegando gente certa?
3. **Mensagem** — a copy está conversando?
4. **Conversão** — o caminho da venda está claro?
5. **Entrega** — o produto entrega o que promete?
6. **Sistema** — ferramentas, processos, time

Pra problema técnico:

1. **Input** (entrada errada?)
2. **Lógica** (código/regra errada?)
3. **Dados** (informação faltando/errada?)
4. **Integração** (sistemas se conversam?)
5. **Permissão** (acesso bloqueado?)

## Template — diagnóstico de venda

```
ROOT: <Mentorada não está vendendo>
├── Oferta
│   ├── Preço errado → Reposicionar
│   ├── Promessa fraca → Reescrever headline
│   └── Garantia ausente → Adicionar
├── Tráfego
│   ├── Volume baixo → Escalar campanha
│   └── Público errado → Refinar lookalike
├── Mensagem
│   ├── Não bate na dor → Briefing 360
│   └── CTA confuso → Simplificar
├── Conversão
│   ├── Página lenta → Otimizar
│   └── Checkout quebrado → Testar
└── Próxima ação prioritária
    └── O que mexer primeiro
```

## Adaptação ao input

- **Sintoma vago:** pergunta primeiro pra refinar (mas só se faltar info crítica)
- **Múltiplos sintomas:** cria mapa por sintoma, não tudo num só
- **Mentorada específica:** integra com perfil dela (PENTA do imperio-diagnostico)

## Conexões cruzadas típicas

- Oferta ↔ Mensagem (oferta forte com copy fraca = mesma raiz)
- Tráfego ↔ Conversão (mais tráfego em página quebrada não resolve)
- Sistema ↔ Tudo (ferramentas afetam tudo)

## Princípio dos 5 porquês

Pra cada causa identificada, pergunte "por quê?" 5 vezes mentalmente. Se a resposta vai parar em causa-mãe que já está no mapa, tá certo. Se aparece causa nova, adiciona.

Exemplo:
1. "Não está vendendo" → por quê?
2. "Tráfego baixo" → por quê?
3. "Anúncio caro" → por quê?
4. "CTR baixo" → por quê?
5. "Criativo fraco" → por quê?
6. "Não tem briefing" ← causa raiz

## Erros a evitar

- Começar pela ação ("o que fazer") em vez de pela causa
- Listar 20 causas — limita a 4-6 pilares, não mais
- Esquecer ações corretivas (mapa sem folhas é só queixa)
- Não definir prioridade (qual causa atacar PRIMEIRO)
