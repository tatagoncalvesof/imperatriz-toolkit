# Calendário de Conteúdo para Redes Sociais — Lançamento Digital

Template de calendário para Instagram (principal) e outras redes.
Adaptar [PLACEHOLDERS] conforme o produto e as datas do lançamento.

---

## Estratégia Geral

### Distribuição de Formatos (Instagram)
- **Feed (carrossel):** 3x por semana — conteúdo educativo, prova social, oferta
- **Reels:** 4-5x por semana — alcance orgânico, ganchos, dicas rápidas
- **Stories:** Diário (8-15 stories/dia durante o lançamento)
- **Lives:** Durante os CPLs + fechamento

### Pilares de Conteúdo
1. **Autoridade** (30%) — ensinar, mostrar expertise, dicas práticas
2. **Conexão** (25%) — bastidores, história pessoal, vulnerabilidade
3. **Prova Social** (25%) — depoimentos, resultados de alunos, números
4. **Oferta** (20%) — produto, bônus, preço, CTA direto

### Hashtags Recomendadas (adaptar por nicho)
```
#[NICHO] #[PRODUTO] #[NOME DO EXPERT]
#empreendedorismofeminino #negociodigital #lancamentodigital
#infoproduto #marketingdigital #mentoria
#transformacao #resultados #liberdadefinanceira
```

## SEMANA 1 — AQUECIMENTO INICIAL (Dia -25 a Dia -19)

## Métricas para Acompanhar

| Métrica | Meta |
|---------|------|
| Alcance por post | +20% vs. média |
| Engajamento (curtidas + comentários + salvamentos) | 3-5% |
| Cliques no link da bio | Rastrear diariamente |
| Novos seguidores durante o lançamento | +500-2000 |
| Views nos Reels | 2-5x seguidores |
| Views nos Stories | 10-20% dos seguidores |
| Taxa de inscrição no evento (CTA para inscrição) | 20-40% |
