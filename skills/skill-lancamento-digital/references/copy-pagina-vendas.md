# Estrutura Completa — Copy de Página de Vendas

Template de página de vendas otimizada para o mercado digital brasileiro.
Seguir a ordem das seções. Adaptar placeholders [ENTRE COLCHETES].

---

## Estrutura Geral da Página

1. Hero / Headline
2. Identificação com a dor
3. Apresentação da solução
4. Para quem é / Para quem não é
5. O que você vai receber
6. Módulos / Conteúdo programático
7. Bônus
8. Empilhamento de valor
9. Preço e condições
10. Garantia
11. Sobre o expert
12. Depoimentos / Prova social
13. FAQ
14. CTA final

## SEÇÃO 1 — HERO / HEADLINE

**Formato:**

```
[PRÉ-HEADLINE — frase de contexto]
[HEADLINE PRINCIPAL — promessa de transformação em 1 linha]
[SUB-HEADLINE — como a transformação acontece + diferencial]

[BOTÃO CTA] — QUERO MINHA VAGA / QUERO COMEÇAR AGORA
```

**Exemplos de headlines:**

- "O método que já ajudou [NÚMERO]+ [AVATAR] a [RESULTADO] em [PERÍODO]"
- "Descubra como [RESULTADO] mesmo que você [OBJEÇÃO PRINCIPAL]"
- "De [SITUAÇÃO ANTES] para [SITUAÇÃO DEPOIS] em [PERÍODO] — sem [OBJEÇÃO]"
- "Pare de [DOR] e comece a [DESEJO] de uma vez por todas"
- "A [MÉTODO/FÓRMULA] que transforma [AVATAR] em [RESULTADO]"

**Elementos visuais:**
- Vídeo de vendas (VSL) de 5-15 minutos OU imagem de impacto
- Logo do produto
- Selos de confiança (Hotmart seguro, garantia, SSL)

## Elementos Visuais Obrigatórios

- [ ] Favicon e logo do produto
- [ ] Cores consistentes com a marca
- [ ] Fotos reais (não banco de imagens genérico)
- [ ] Screenshots de depoimentos reais
- [ ] Selos: garantia, Hotmart seguro, SSL
- [ ] Timer/countdown (se em período de lançamento)
- [ ] Botões CTA em cor contrastante, repetidos a cada 2-3 seções
- [ ] Mobile-first (maioria acessa pelo celular)
- [ ] Vídeo de vendas (VSL) no topo

## Dicas de Conversão

- Repetir o CTA pelo menos 4-5 vezes ao longo da página
- Usar ancoragem de preço (mostrar valor total antes do preço real)
- Incluir timer de countdown durante o período do carrinho
- Adicionar "Últimas X vagas" se for escassez real
- Usar exit-intent popup com desconto ou bônus extra
- Incluir chat/WhatsApp flutuante para dúvidas
- A/B testar headlines diferentes
- Velocidade de carregamento: página deve abrir em menos de 3 segundos
