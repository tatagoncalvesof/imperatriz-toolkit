# Gerador de Oferta Irresistivel — High Ticket

Transformar blueprint + historia do metodo em uma oferta impossivel de ignorar usando a Value Equation, Stack de Valor empilhado e copy de conversao.

## Value Equation (Fundamento Central)

Toda oferta irresistivel segue esta equacao:

```
                 Sonho Realizado  x  Probabilidade Percebida
VALOR = ──────────────────────────────────────────────────────
                 Tempo Estimado  x  Esforco/Sacrificio
```

**Maximizar o numerador:**
- Sonho: Elevar a transformacao prometida (resultado final)
- Probabilidade: Aumentar a crenca de que VAI funcionar (provas, metodo, garantia)

**Minimizar o denominador:**
- Tempo: Encurtar o caminho (atalhos, frameworks, templates prontos)
- Esforco: Reduzir o trabalho necessario (feito pra voce, comunidade, suporte)

## Workflow em 7 Passos

### Passo 0: Receber Inputs

Solicitar 2 documentos:
1. **Blueprint Estrategico** — Estrutura do metodo/produto
2. **Historia do Criador** — Gerada com `/skill-historia-metodo` ou descrita

Se nao tiver a historia, sugerir: "Posso gerar sua historia de autoridade com `/skill-historia-metodo` antes de montar a oferta."

### Passo 1: Extracao Inteligente

Analisar os inputs e extrair automaticamente:

| Elemento | O que buscar |
|----------|-------------|
| PUV (Proposta Unica de Valor) | O que diferencia esta oferta de tudo no mercado |
| Avatar | Dores centrais, desejos, medos, situacao atual vs. desejada |
| Core Deliverables | Entregaveis principais (modulos, sessoes, ferramentas) |
| Aceleradores | Bonus, comunidade, suporte, IA, templates |
| Garantias existentes | Qualquer promessa de resultado ou reembolso |
| Preco e pagamento | Faixa de preco, opcoes de parcelamento |
| Escassez real | Vagas limitadas, turma, prazo |
| Historia do criador | Origem, insight, validacao, visao |

**Saida:** Resumo executivo da oferta em 1 paragrafo.

### Passo 2: Fundamentos da Oferta (Checkpoint 1)

Confirmar com o usuario:

1. **Preco oficial** ou faixa desejada
2. **Garantia** — Sugerir opcoes. Ver [references/garantias-modelo.md](references/garantias-modelo.md)
3. **Condicoes de pagamento** — A vista com desconto, parcelado, entrada + saldo

**Saida:** Proposta de valor atualizada com preco e garantia confirmados.

### Passo 3: Stack de Valor (Checkpoint 2)

Organizar em 3 camadas usando o framework de objecoes:

**Camada 1 — Core Deliverables:**
Para cada entregavel: nome memoravel, descricao, beneficio direto, dor que resolve, valor-ancora.

**Camada 2 — Bonus Estrategicos (Anti-Objecao):**
Cada bonus mata uma objecao especifica. Ver [references/stack-de-valor.md](references/stack-de-valor.md)

| Objecao | Tipo de bonus | Exemplo |
|---------|--------------|---------|
| "Nao tenho tempo" | Acelerador | "Plano de Arranque em 7 Dias" |
| "E muito caro" | Valor adicional | "Mentoria Individual (valor R$X)" |
| "Nao sei se funciona" | Prova | "Casos reais + acesso a ex-alunos" |
| "Nao vou conseguir" | Suporte | "Acompanhamento semanal por 90 dias" |
| "Ja tentei antes" | Diferencial | "Diagnostico personalizado do que deu errado" |
| "Preciso pensar" | Urgencia | "Bonus X exclusivo para quem entra hoje" |

**Camada 3 — Garantia (Risco Reverso):**
Risco ZERO para o comprador. Transferir todo o risco para o vendedor.

**Saida:** Stack completo com valores-ancora por item.

### Passo 4: Ancoragem de Preco 10x

Somar valor-ancora de todos os entregaveis e bonus:

```
ENTREGAVEIS CORE:
  [Nome 1] ..................... R$ X.XXX
  [Nome 2] ..................... R$ X.XXX
  [Nome 3] ..................... R$ X.XXX

BONUS:
  [Bonus 1] .................... R$ X.XXX
  [Bonus 2] .................... R$ X.XXX
  [Bonus 3] .................... R$ X.XXX

VALOR TOTAL: R$ XX.XXX+
INVESTIMENTO REAL: R$ X.XXX
ECONOMIA: XX%
```

**Principios psicologicos aplicados:**
- Anchoring Effect: Primeiro numero alto ancora a percepcao
- Contrast Effect: Preco real parece pequeno vs. valor total
- Loss Aversion: "Voce perde R$XX.XXX de valor se nao agir"
- Mental Accounting: Dividir em "R$X por dia" ou "menos que um cafe"

### Passo 5: Transformacao e Prova

Construir a secao emocional + racional:

1. **Super Promessa** — Baseada no blueprint + historia. 1 frase poderosa.
2. **Plausibilidade Empirica** — Historia do criador + depoimentos + numeros
3. **Plausibilidade Logica** — Mecanismo do metodo em 3-4 etapas (por que funciona)
4. **Quick Wins** — Resultados visiveis em D7/D14 (prova rapida)
5. **Custo de Nao Agir** — O que o avatar PERDE ficando parado

### Passo 6: Copy Final (Checkpoint 3)

Gerar copy em 3 formatos. Ver [references/templates-copy.md](references/templates-copy.md)

**Formato 1 — Landing Page Longa (~3.000-5.000 palavras):**
Headline (3 variacoes) → Super promessa → Plausibilidade → Stack de valor → Garantia → Prova social → FAQ (objecoes) → Fechamento em 3 caminhos → CTA

**Formato 2 — Pitch Curto (~150 palavras):**
Para video de vendas, webinar, call de vendas.

**Formato 3 — One-Liner (140 caracteres):**
Para anuncios, bio, headlines.

### Passo 7: Pacote de Testes

Entregar:
- 3 headlines para split test
- 2 subheadlines
- 2 CTAs
- Checklist de metricas: Opt-in >= 25%, Conversao >= 5-10% (frio) / >= 20-30% (quente), NPS >= 8.0

## Regras de Ouro

1. **Nunca inventar numeros** — So usar dados reais do cliente
2. **Bonus > desconto** — Adicionar valor, nunca reduzir preco
3. **Garantia forte = mais vendas** — Risco reverso aumenta conversao
4. **Escassez REAL** — Nunca mentir sobre vagas/prazo
5. **Especificidade mata genericidade** — "12 semanas" > "em breve"
6. **1 CTA por secao** — Nao confundir com multiplas opcoes
7. **Emocao + logica** — Compra e emocional, justificativa e logica
8. **Formato BR** — Valores em R$, exemplos brasileiros, tom adequado ao publico
